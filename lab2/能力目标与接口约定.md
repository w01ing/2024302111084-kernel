# lab2 · 能力目标与接口约定（陷入与中断：syscall 与控制台）

> 你的内核现在能启动、能打印。本轮让它学会**被打断并完美复原**：
  进入/离开 U 态、响应时钟与 UART 中断、处理系统调用，
  并跑起第一个用户程序（sh）。
  允许"假调度"——内核办完事直接返回原进程；这笔债 lab4 还。

## 1. 能力目标（由你设计并实现）

1. trampoline 协议落地：U↔S 切换时 sp/sscratch 的交换、trapframe 的
   保存与恢复（trampoline.S 是协议的另一半，注释即文档）。
2. usertrap：系统调用分发（含 epc 前移语义）与中断分发。
3. syscall 参数传递：argint/argaddr/argstr 的等价物（命名自定）。
4. 中断驱动控制台＋输入缓冲：按你的 `LAB2_BUF_SEMANTICS`（行缓冲/
   字符流）、`LAB2_BUF_SIZE`、`LAB2_TICK` 设计缓冲与唤醒。
5. 最小进程机制：够用即可——装得下"运行 sh、sh fork 出子进程跑
   hi/spin、wait 回收"。（页表还没有：`satp=0` 直映＋PMP 划界是
   合法过渡形态，lab3 开启 SV39。）
6. sys_exec 从**内嵌程序表**加载程序（见 §2.4；磁盘与文件系统是
   lab6 的债）。

## 2. 接口约定（合同）

1. **ecall ABI**：a7=调用号，a0–a2 参数，a0 返回；用户侧桩由
   `user/usys.pl` 生成——**调用号表即合同**，你的内核侧分发必须
   与之一致；对未知/未实现的调用号必须返回确定错误（-1），
   不得 panic。
2. **trampoline ABI**：TRAMPOLINE/TRAPFRAME 地址与交换协议，
   见 kernel/trampoline.S 头注释。
3. **exec 签名**：完整 xv6 形式 `exec(name, argv)`；lab2 实现允许
   忽略 argv（内嵌程序均无参数）——lab5 完整化，又一笔债。
4. **内嵌程序表 ABI**（Makefile.upgrade 自动生成 `kernel/userimg.S`）：
   `_uprog_table` 每项 = `{u64 start; u64 end; char name[]}`（.balign 8），
   以 `{0,0}` 结尾；程序为基址 0 的平铺二进制。
5. **运行合同**：`make qemu` 启动后进入 sh；`support/inject_uart.py`
   灌入一行命令能正确执行并回显。

## 3. 设计决策（规格必须回答；验收从这里面抽题）

- trapframe 放哪、多大、每进程一份还是全局？谁在何时切换它？
- 输入缓冲的数据结构与锁；"检查-入睡"在 console 读上怎么落地；
  行缓冲与字符流语义差别体现在哪几行？
- syscall 分发表怎么组织（switch/表驱动/生成式）？错误码约定？
- fork 在无页表时代怎么复制用户程序镜像？复制到哪里、谁记账？
- 用户指针现在**直接解引用**是允许的——记下这笔债，lab3 还。

## 4. 赠送件（gifts/，不可改）

trampoline.S、usys.pl、user.h、ulib.c、printf.c（用户态）；
课程自制：sh.c、hi.c、spin.c、user.ld、Makefile.upgrade
（用户程序内嵌方案：UPROGS 编为平铺二进制并 .incbin 进内核）。
Makefile 合并：把 Makefile.upgrade 的规则并入你的 Makefile，
并把 `kernel/userimg.o` 加进 OBJS；三固定项不动。

## 5. 里程碑自检

1. `make qemu` 进 `sh>`，键入 `hi`（inject_uart 灌入亦可）出 pid；
2. `spin` 运行时敲键盘，内核输出与程序输出交错不乱；
3. 非法调用号（改一行 usys 临时验证后还原）返回 -1 不死机。

**回归**：本轮起 banner 随启动打出（lab1 输出通道未断）。

## 6. 耗时参考

规格 5h / 实现 10h（trapframe＋分发从零设计，调试量大于 v2 估）。

## 测试与核对（已交付，随包 support/tests/）

- user 测试程序集：`badecall`（非法 ecall 返回 -1）与 `bufstorm`
  （输入缓冲边界，行/字符流通用）已随包交付，见 `support/tests/README-tests.md`。
- usys 调用号表核对结论（2026-09-05）：22 个桩 ↔ syscall.h 22 个
  `SYS_*` 一一对应，编号 1..22 连续无缺口；sh/hi/spin 所用调用
  （exec/exit/fork/wait）全部有桩。**核对通过。**
