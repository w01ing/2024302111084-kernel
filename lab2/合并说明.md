# 合并说明(lab2)

1. 在你的树根执行: unzip packs/lab2.zip -d .
   (得到 gifts/ support/ 能力目标与接口约定.md 本文件)
2. gifts/ 内全部文件为**不可改赠送件**,放进树中对应位置;
   若与你树中已有文件同名,以包内版本为准(先 git diff 看一眼再覆盖)。
3. 先读《能力目标与接口约定.md》再动工;测试在 support/。
4. 合并完成后:
     git add -A && git commit -m "lab2 pack merged" && git tag lab2-start
5. 交付前:
     git tag lab2-submit
     git archive --format=zip -o 提交-lab2-<学号>.zip lab2-submit

课程参考实现(MIT xv6 为公开阅读参考)不含你的接口与参数——
接口以本包约定为准。
