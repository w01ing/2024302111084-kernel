# 实验规范 · dump_pagetable 观测接口规范（lab3 支撑规范说明）

> 本规范并非具体代码实现，而是**统一的输出格式与观测规范**：教师现场验收与学生阶段自检均按此统一格式解析输出内容。
> 版本：v2（2026-09-29，随 lab3 增量包 v2 修订：perm 示例统一为四位、补充 A/D 位说明方式）。

## 建议调用点

内核在**完成第一个用户态进程的页表装配后**，向串口控制台输出一次
dump 块信息（具体调用时机由学生自主设计——建议封装为独立函数，以便现场验收时能够按需重放）。

## 输出格式规范（逐行输出，自动化测试脚本按行首前缀匹配）

```
DUMP-PAGETABLE begin
L2 va=0x..0 pa=0x..0 perm=----     ← 每个非叶表项输出一行（非叶无 rwx 权限）
L1 va=0x..0 pa=0x..0 perm=----     ← 同上
LEAF va=0x..0 pa=0x..0 perm=rw-u   ← 每个叶子页表项（Leaf PTE）输出一行
DUMP-PAGETABLE end
```

- `va` 表示该表项所管辖虚拟地址空间的**起始地址**，`pa` 表示下一级页表或物理页面的物理地址；
- `perm` 依次按 R/W/X/U 顺序以**四个字符**表示访问权限，未置位的权限位使用 `-` 占位
  （示例：代码页 `r-xu`、数据页 `rw-u`、跳板页 `r-x-`、陷入帧页 `rw--`、非叶表项 `----`）；
- **A/D 位说明**：A（Accessed）与 D（Dirty）属于硬件管理的运行时状态位，**不在 perm 四位中输出**；
  其管理方式（硬件自动置位还是软件维护）在现场验收时以口头说明方式陈述即可，不作为格式检查项；
- 输出行数不限；建议按虚拟地址 `va` 升序打印（便于与 lab0 中绘制的地址空间快照图对照检查）。

## 主要用途

1. 里程碑自检：将实际输出与 lab0 规划的虚拟内存快照逐项比对，准确阐述每一个表项与权限位的含义；
2. 现场验收：现场考查重点操作之一 —— 现场触发重放 dump 并进行代码与设计讲解；
3. lab4 回归测试：lab4 调度器改造后，必须重新运行本 dump 验证虚拟内存结构保持正确。
