1. 在工程根目录执行：unzip lab3-v2-20260929.zip -d .

2. gifts/ 目录内的文件为**预置支撑代码（请勿修改）**，请复制到工程中对应位置；
   若与工程中已有文件同名，以增量包内版本为准（建议先用 git diff 核对差异后再覆盖）。
3. **v2 新增：两份预置文件的修复覆盖**（本次解压会与工程内同名文件冲突，属预期）：
   - `gifts/kernel/trampoline.S` → 覆盖工程 `kernel/trampoline.S`：
     相对 lab2 增量包版本仅修复段声明（原 `.section trampsec` 无可分配/可执行属性，
     跳板代码不进入内核镜像、符号地址为 0；修复为携带 "ax" 属性并段内 4KB 对齐）。
     覆盖前 `git diff` 核对：差异应仅为文件内注释标出的修复行。
   - `gifts/kernel/riscv.h` → 覆盖工程 `kernel/riscv.h`：
     相对基线包版本仅补 include guard（防重复包含保护），不改变任何宏与语义。
   若你此前已自行修复过这两处（修复方式不同但等价），保留你自己的版本同样可行，
   请在设计笔记中注明。
4. **lab2 遗留构建方案的解除**：若你在 lab2 为规避小地址绝对寻址问题自行采用了
   "固定基址重链接"等构建方案，本实验开启分页、用户程序映射到虚拟地址 0 之后，
   该方案必须移除（用户程序回到基址 0 链接，绝对寻址引用在用户页表内天然有效）。
5. 动手编写代码前，请先通读《能力目标与接口约定.md》。官方测试程序位于
   support/tests/ 目录（拷贝到 user/ 后按 lab2 既有方式纳入构建），
   其余支撑组件位于 support/ 目录。
6. 合并完成后建议执行：
     git add -A && git commit -m "lab3 pack merged (v2-20260929)" && git tag lab3-start

     git tag lab3-submit
     git archive --format=zip -o 提交-lab3-<学号>.zip lab3-submit
